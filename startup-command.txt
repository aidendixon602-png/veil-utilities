# ================================================================
# Wispbyte / Pterodactyl Fast Startup Command
# ================================================================
# Paste this into your Wispbyte panel under the "Startup" tab
# in the "Startup Command" field.
#
# Why container boots used to take 2 minutes:
# The default panel command ran `pip install -U --prefix .local -r requirements.txt`
# on EVERY boot, forcing pip to query PyPI over the internet for upgrade checks on 20+ packages.
#
# How this command fixes it to boot in ~2-3 seconds:
# Uses `cmp -s` to compare requirements.txt with a local hash file.
# If requirements haven't changed, pip install is SKIPPED completely (takes 2ms).
# If requirements.txt is ever modified, it runs pip install and updates the hash.

if [ -f requirements.txt ]; then if ! cmp -s requirements.txt .requirements.hash 2>/dev/null; then pip install --prefix .local -r requirements.txt && cp requirements.txt .requirements.hash; fi; fi; python main.py
